# Chabahar Brine Dispersion Modeling

M.Sc. research project conducted at the University of Tehran on the numerical simulation of desalination brine dispersion in Chabahar Bay, Iran.

## Project Overview

The study investigated the transport and dilution of hypersaline effluent from a reverse-osmosis desalination plant under different tidal, wind, and discharge conditions.

A three-dimensional hydrodynamic model was developed using MIKE 3 Flow Model FM. The modeling workflow included:

- 3D hydrodynamic simulation
- Continuity and momentum equations
- Salinity transport and diffusion
- Mesh and vertical-layer sensitivity analysis
- Boundary-condition definition
- Model calibration and validation
- Scenario-based analysis of brine dispersion
- Evaluation of alternative outfall configurations

## Model Validation

The hydrodynamic model was calibrated against measured water-level data from Chabahar Port.

Performance indicators:

- Pearson correlation coefficient: 0.92
- Nash–Sutcliffe Efficiency (NSE): 0.85
- Root Mean Square Deviation (RMSD): 0.22 m

## Main Results

The simulations showed that the existing discharge configuration can produce elevated salinity and long-distance plume dispersion under some environmental conditions.

Alternative outfall configurations were simulated to improve dilution performance. The selected alternative reduced salinity in the near-field region and provided a more suitable discharge configuration.
